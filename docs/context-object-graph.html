ContextRuntime · core data model

The context-object graph

Every unit of potential model-visible content is a node. Every edge is a number ContextScope or CacheScope already computes. The graph lives in the runtime — never in the prompt.

Edges — and the number each one produces

This is the point of the whole model: the graph isn’t new work, it’s the normalized form of what the profilers already compute. Each edge maps to a measured pool or a concrete runtime operation.

The runtime’s operations are graph queries

Nothing about this graph is exotic. Every ContextRuntime behavior is a traversal or aggregation over it — which is exactly why it’s the right data model rather than a bolt-on.

Occupancy & cost ledger

Sum token estimates over resident edges; weight by the cache tier on each edge for the economic view.

Σ token_est(o) over RESIDENT_IN(o→r)

Dedup before admission

If an object about to be admitted has a duplicate already resident, deliver a reference instead of the bytes.

∃ DUPLICATE_OF(o→o′) ∧ resident(o′) ⇒ ref

Delta on change

When an edited object supersedes a delivered one, ship the diff, not the whole thing.

SUPERSEDES(o→o′) ∧ delivered(o′) ⇒ diff

Admission bundle

Pack a target plus its dependency closure under a token budget, so a small slice is never incoherent.

closure(DEPENDS_ON, target) ≤ budget

Eviction (gateway)

Drop objects long-resident and outside the current task’s dependency frontier.

span(RESIDENT_IN) > H ∧ ∉ frontier ⇒ evict

Capsule

The induced subgraph over high-trust, task-relevant nodes — with source references replacing content.

induce{ trust≥T ∧ relevant } + refs

Cache-break cost

The size of the island at the moment it broke, attributed by cause.

CacheIsland.size @ BROKE, group by cause

Provenance / injection guard

Trust flows on edges; external content can never be promoted from data to instruction.

trust(EXTERNAL) ⇒ data-only, never instruction
The one invariant. This graph lives in the runtime — SQLite adjacency tables plus a content-hash store — not in the prompt. The model receives a manifest: a flat projection of the object ids and levels it was given, plus the selected slices. Serializing the graph itself into context would add tokens, which is the exact mistake the whole design avoids. The graph reduces tokens by deciding what becomes prefix; it never becomes prefix.
