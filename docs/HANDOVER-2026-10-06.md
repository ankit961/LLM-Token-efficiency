## 1. What the project is trying to do

The question is whether coding agents such as Claude Code can run on fewer tokens and dollars
without getting worse at the task.

An agent re-sends its whole context on every model call. Every early token is therefore paid many
times, mostly at the cheap prompt-cache rate. That means the real cost depends on three things:
- what enters the context (**admission**);
- how long it stays (**lifetime**);
- whether removing it breaks the cache (**cache economics**).

### Bug fixes (regression tests in `tests/test_gateway_doctor_fixes.py`)
1. **Break-even rule.** It is now `read·R·(E+1) ≥ (write−read)·(S−R)`. It used to be unreachable on Anthropic prices. It is tested never to fire at a loss against the cache simulator.
2. **Persistent stubs** are forwarded even when thinking removal is off.
3. **Rejected mutations.** When the API rejects a mutated request, that conversation's breaker trips and later requests pass through unchanged.
4. **Per-conversation state.** Scheduler state is kept per conversation, and the newest kept thinking is never stripped.
5. **`doctor --prefix --no-capture`** no longer crashes.
6. **Same-project filter.** The doctor now matches paths that contain `_`.
7. **Graph ranking** is off by default. The B1 floor stays at 400, and `B1_DECISION.md` records why.

None of these fixes has been run in a live session yet.

## 5. Standing rules

- **No paid runs** (Claude, Codex or any other provider) without the owner's explicit go.
- **Privacy sweep before every commit:** `python3 scripts/privacy_sweep.py --staged`.
  - The list of names it guards lives in the gitignored `.privacy-patterns` file. Copy it to a new machine by hand and never commit it.
  - Grading data rule: only public Django patches and task IDs leave the machine.
- **Frozen records get dated correction blocks, never silent edits.** Do not change the frozen observation runtime or corpus without a measured defect.
- **"ContextRuntime does nothing when uncertain."** Every hook and gateway path fails open.
- **Avoid backticks inside `git commit -m "..."`** (zsh substitutes them).
